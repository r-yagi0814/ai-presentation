02 ─ What is AI Generation

🤖AI生成とは

AIが学習したデータをもとに、新たなコンテンツ（テキスト・画像・音声・動画・コードなど）を自律的に生成する技術の総称。
従来の「検索・分類・予測」から 「創造・生成」 へとAIの役割が拡大。
領域概要代表的なツール
テキスト文章・コード・翻訳の生成ChatGPT, Claude, Gemini
画像イラスト・写真風画像の生成Midjourney, DALL-E, Stable Diffusion
音声声の合成・音楽生成ElevenLabs, Suno
動画映像・アニメーションの生成Sora, Runway, Kling
コードプログラムの自動生成・補完GitHub Copilot, Cursor

05 ─ Technology

⚙️主な技術・手法

LLM（大規模言語モデル）

  • 大量のテキストデータを学習した言語モデル
  • Transformer をベースに次のトークンを予測して文章を生成
  • GPT-4o / Claude 3 / Gemini

画像生成AI（Diffusion Model）

  • ノイズから徐々に画像を復元するプロセスで高品質な画像を生成
  • テキストプロンプトを与えることで意図した画像を出力
  • Stable Diffusion / Midjourney / DALL-E 3

音声・動画生成

  • 音声合成（TTS）：テキストから自然な音声を生成
  • 音楽生成：ジャンル・雰囲気を指定して楽曲を自動作成
  • 動画生成：静止画や文章から短尺動画を生成（急速進化中）

マルチモーダルAI

  • テキスト・画像・音声など複数の形式を同時に理解・生成
  • 画像を見て説明文を生成、音声をテキスト化、等
  • GPT-4o / Gemini 1.5 Pro / Claude 3.5 Sonnet

🚀 Cursor & Claude Code で始める本格 AI 開発（予定）
コードを書きながら AI との協働開発を体験します。

🖥️ Cursor

  • AI ペアプログラマーとして動作するエディタ
  • 自然言語でコード全体を編集・リファクタ
  • コンテキストを理解したコード補完・提案

⚡ Claude Code

  • CLI で動く Anthropic 製コーディングエージェント
