基本用語BASICS

生成AI（AI生成）

せいせいエーアイ（エーアイせいせい）

AIが学習したデータをもとに、文章・画像・音声・動画・プログラムなどの新しいコンテンツを作り出す技術の総称です。

従来のAIが得意だった「検索・分類・予測」に加えて、「創造・生成」までできるようになったことが大きな変化です。

関連：LLM　拡散モデル
▲ 目次へ戻る

LLM（大規模言語モデル）

エルエルエム（だいきぼげんごモデル）

Large Language Model の略。大量の文章を学習し、人間のように文章を理解・作成できるAIモデルです。ChatGPT・Claude・Gemini などの中核にあたります。

文章の続きとして「次に来そうなトークン」を予測し、それを繰り返すことで文章を組み立てます。

関連：Transformer　トークン
▲ 目次へ戻る

Transformer

トランスフォーマー

2017年に Google の研究者らが発表した、AIの基本的な仕組み（アーキテクチャ）です。文中の言葉同士の関係を「注意（Attention）」という仕組みで捉えるのが特徴です。

現在の多くのLLMがこの仕組みを土台にしています。ChatGPT の「GPT」の「T」も Transformer の頭文字です。

▲ 目次へ戻る

トークン

トークン

AIが文章を処理するときの最小単位です。単語や文字の一部に相当し、日本語ではおおむね1文字前後が1トークンになります。

AIが一度に読める文章量の上限や、API利用時の料金もトークン数で数えるのが一般的です。

▲ 目次へ戻る

プロンプト

プロンプト

AIに対する指示文・質問文のことです。目的・前提・出力形式などを具体的に書くほど、期待に近い回答が得られやすくなります。

画像生成AIに「どんな絵を描いてほしいか」を文章で伝えるものを「テキストプロンプト」と呼びます。

▲ 目次へ戻る

拡散モデル（Diffusion Model）

かくさんモデル（ディフュージョンモデル）

ノイズ（砂嵐のような画像）から少しずつノイズを取り除いて画像を浮かび上がらせる方式の生成モデルです。現在の画像生成AIの主流の方式です。

代表例：Stable Diffusion　Midjourney　DALL-E
▲ 目次へ戻る

マルチモーダルAI

マルチモーダルエーアイ

テキスト・画像・音声など、複数の種類（モーダル）の情報をまとめて理解・生成できるAIです。

例：写真を見て説明文を書く、音声を聞いて文字に起こす、など。

代表例：GPT-4o　Gemini　Claude
▲ 目次へ戻る

音声合成（TTS）

おんせいごうせい（ティーティーエス）

TTS は Text-to-Speech の略。テキストを自然な音声に変換する技術です。ナレーション作成や読み上げなどに使われます。

代表例：ElevenLabs
▲ 目次へ戻る

ハルシネーション

ハルシネーション

英語で「幻覚」の意味。AIが事実と異なる内容を、もっともらしく回答してしまう現象です。存在しない資料や数値を作り出すこともあります。

AIの回答は鵜呑みにせず、ファクトチェックすることが大切です。

▲ 目次へ戻る

ファクトチェック

ファクトチェック

情報が事実かどうかを確認・検証することです。AIの回答は、公式サイトや一次情報で裏付けを取ってから使いましょう。

▲ 目次へ戻る

ノーコード

ノーコード

プログラムを書かずに、画面操作だけでアプリや仕組みを作ることです。ChatGPT の GPTs はノーコードで作成できます。

▲ 目次へ戻る

チャットAI・機能CHAT AI

ChatGPT

チャットジーピーティー

OpenAI が提供する対話型AIです。文章作成・アイデア出し・コード補助など、幅広い用途に使える汎用的なツールです。

GPT は Generative Pre-trained Transformer（事前学習済みの生成型Transformer）の略です。

▲ 目次へ戻る

GPT-4o / GPT-4o mini

ジーピーティー・フォー・オー ／ ジーピーティー・フォー・オー・ミニ

ChatGPT で使われている OpenAI のAIモデルの名前です。「o」は omni（あらゆる）の意味で、文章・画像・音声を扱えるマルチモーダルなモデルです。

「mini」は軽量版で、発表資料では ChatGPT 無料版の主なモデルとして紹介しています。

▲ 目次へ戻る

Claude

クロード

Anthropic が提供する対話型AIです。長い文書の読み込み・要約・分析や、論理的な文章作成が得意です。

資料中の「Claude 3」「Claude 3.5 Sonnet（ソネット）」はモデルの世代・種類を表す名前です。

▲ 目次へ戻る

Gemini

ジェミニ

Google が提供する対話型AIです。Google 検索を生かした最新情報の取得や、Google Workspace との連携が強みです。

「Gemini 1.5 Pro」はモデルの名前です。

▲ 目次へ戻る

Microsoft Copilot

マイクロソフト・コパイロット

Microsoft が提供するAIアシスタントです。Copilot は「副操縦士」の意味。Web版に加え、Microsoft 365 の Word・Excel・Teams などに組み込まれて使えるのが特徴です。

関連：GitHub Copilot（開発者向けの別製品）
▲ 目次へ戻る

カスタム指示

カスタムしじ

ChatGPT に、自分の役職・口調・よく使う出力形式などを事前に登録しておく機能です。毎回同じ説明をしなくても、好みに合った回答が返ってきます。

▲ 目次へ戻る

GPTs

ジーピーティーズ

ChatGPT 上で、特定の業務に特化したオリジナルのAIを作成・共有できる機能です。指示や参考資料を設定するだけで、ノーコードで作れます。

▲ 目次へ戻る

プロジェクト機能

プロジェクトきのう

複数のチャットを1つのプロジェクトにまとめ、共通の前提や資料を持たせられる機能です。案件ごとに情報を整理したいときに便利です。

▲ 目次へ戻る

料金プラン（Free / Plus / Pro / Advanced）

りょうきんプラン（フリー / プラス / プロ / アドバンスト）

Free は無料プラン、Plus・Pro・Advanced はサービスごとの有料プランの名前です。有料プランでは、高性能モデルの利用回数や機能が拡張されます。

※ 料金や無料枠の内容は変更されることがあります。最新情報は各公式サイトで確認してください。

画像・音声・動画生成AIMEDIA GENERATION

Midjourney

ミッドジャーニー

テキストから画像を生成するAIサービスです。芸術性の高いイラストや写真風の画像に定評があります。

▲ 目次へ戻る

DALL-E（DALL-E 3）

ダリ（ダリ・スリー）

OpenAI の画像生成AIです。ChatGPT から文章で指示するだけで画像を作れるため、資料のイメージ作成などに活用できます。

名前は画家サルバドール・ダリと映画「WALL-E（ウォーリー）」に由来します。

▲ 目次へ戻る

Stable Diffusion

ステーブル・ディフュージョン

Stability AI などが公開した画像生成モデルです。モデルが一般に公開されているため、自分のPCで動かしたり、カスタマイズしたりできるのが特徴です。

関連：拡散モデル
▲ 目次へ戻る

ElevenLabs

イレブンラボ（イレブンラブズ）

自然な読み上げ音声を作れる音声合成AIサービスです。多言語のナレーション作成や、声の再現などに対応しています。

▲ 目次へ戻る

Suno

スーノ

ジャンルや雰囲気、歌詞を指定するだけで、歌入りの楽曲を自動生成できる音楽生成AIです。

▲ 目次へ戻る

Sora

ソラ

OpenAI の動画生成AIです。文章や画像から短い動画を生成できます。名前は日本語の「空」に由来するとされています。

▲ 目次へ戻る

Runway

ランウェイ

動画の生成・編集をAIで行えるサービスです。映像制作の現場でも使われています。

▲ 目次へ戻る

Kling

クリング

中国の快手（Kuaishou／クワイショウ）が開発した動画生成AIです。文章や画像から、動きの自然な動画を生成できます。

▲ 目次へ戻る

開発・コーディングDEVELOPMENT

GitHub Copilot

ギットハブ・コパイロット

GitHub（Microsoft 傘下）が提供する、プログラミング支援AIです。エディタの中で、書きかけのコードの続きを提案（コード補完）したり、チャットで質問に答えたりします。

無料版でも、発表資料時点で月2,000回のコード補完・月50回のAIチャットが使えます。

▲ 目次へ戻る

Cursor

カーソル

AI機能を深く組み込んだコードエディタです。VS Code をベースにしており、チャット感覚でコードベース全体の編集やリファクタができます。

▲ 目次へ戻る

Devin

デビン

Cognition 社が開発した「AIソフトウェアエンジニア」です。指示を受けると、自律的にコードを書き・テストし・修正するところまで行います。

関連：AIエージェント
▲ 目次へ戻る

Claude Code

クロード・コード

Anthropic 製のコーディングエージェントです。CLI（ターミナル）などで動き、ファイルの読み書きやコマンド実行をしながら開発を進めます。

CLAUDE.md でプロジェクトのルールを伝えたり、スキルやフックで動きをカスタマイズしたりできます。

▲ 目次へ戻る

VS Code（Visual Studio Code）

ブイエス・コード（ビジュアル・スタジオ・コード）

Microsoft が提供する無料のコードエディタです。拡張機能が豊富で、GitHub Copilot も拡張機能として利用できます。

▲ 目次へ戻る

JetBrains

ジェットブレインズ

IntelliJ IDEA・PyCharm などの開発ツール（IDE）を提供している会社です。これらのツールでも GitHub Copilot を利用できます。

▲ 目次へ戻る

エディタ（コードエディタ）

エディタ

プログラムを書くためのソフトウェアです。色分け表示や入力補助など、コードを書きやすくする機能を備えています。より多機能なものは IDE（アイディーイー／統合開発環境）と呼ばれます。

▲ 目次へ戻る

コード補完

コードほかん

書きかけのコードから、続きを予測して自動で提案してくれる機能です。スマホの予測変換のプログラム版のようなものです。

▲ 目次へ戻る

コードベース

コードベース

1つのプロジェクトを構成するソースコード全体のことです。

▲ 目次へ戻る

リファクタ（リファクタリング）

リファクタ（リファクタリング）

プログラムの動きは変えずに、中身を読みやすく・直しやすく整理することです。

▲ 目次へ戻る

CLI

シーエルアイ

Command Line Interface の略。マウスではなく、黒い画面（ターミナル）に文字でコマンドを入力して操作する方式です。

▲ 目次へ戻る

AIエージェント（コーディングエージェント）

エーアイエージェント

質問に答えるだけでなく、目的に向けて自分で計画を立て、ツールを使って作業し、結果を確認するところまで自律的に進めるAIです。プログラミング向けのものをコーディングエージェントと呼びます。

代表例：Claude Code　Devin
▲ 目次へ戻る

ペアプログラマー

ペアプログラマー

2人1組でプログラムを書く「ペアプログラミング」の相方のことです。AIがその相方役として、隣で提案やレビューをしてくれるイメージです。

▲ 目次へ戻る

CLAUDE.md

クロード・エムディー

Claude Code が作業開始時に読み込む、プロジェクトのルールや前提を書いておくファイルです。チームのルールをAIに覚えさせることができます。

「.md」は Markdown 形式のファイルであることを表します。

▲ 目次へ戻る

Markdown

マークダウン

「#」で見出し、「-」で箇条書きのように、簡単な記号で文章の構造を表す書き方です。拡張子は「.md」。発表資料の原稿もこの形式で書かれています。

▲ 目次へ戻る

カスタムスキル

カスタムスキル

よく使う作業手順や指示をまとめて登録しておき、必要なときに呼び出せるようにしたものです。Claude Code ではスラッシュコマンドとして呼び出せます。

▲ 目次へ戻る

スラッシュコマンド

スラッシュコマンド

「/review」のように、「/（スラッシュ）」から始まる短い命令です。入力するだけで登録済みの操作を実行できます。

▲ 目次へ戻る

フック

フック

「ファイルを保存したとき」など特定のタイミングで、自動的に処理を実行する仕組みです。自動チェックや通知などに使います。
